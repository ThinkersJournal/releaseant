kind: Added: `releaseant cite-update`, the X.Y citation update for a minor bump (red-first test, self-test on vulkane, fireline, KISS)
---
After a minor (or pre-1.0 breaking) bump is published and read back, `releaseant cite-update --root <tree> --old X.Y --new X.Y --served <version the registry served before the bump>` lists every place that still cites the old `X.Y` of the project's own crates and prints the edit as a unified diff (`--patch-out FILE` also writes it; `--apply` rewrites a worktree; the default changes nothing). It exists because the vulkane 0.26 -> 0.27 and 0.27 -> 0.28 bumps each needed the same hand edit (README x4, three `//!` examples, `vulkane_derive/README.md`, own-crate requirements), recorded as three hand updates in `.lane-state/stamp-hand-updates.md`, and a stamp-time edit was reverted once because the harness self-test compares with the SERVED version: the tool is for publish time, after the read-back, and does not run at the stamp.

Citation shapes: a requirement on an own crate (`name = "X.Y"`, `version = "X.Y"` on a line naming an own crate or in its `[dependencies.name]` table, `^`/`~` kept), `name@X.Y`, `docs.rs/name/X.Y`, in `Cargo.toml`, Markdown and Rust doc comments (`//!`, `///`); code string literals and other projects' crates (`tree-sitter = "0.27"`) are not touched. Refused and listed: `CHANGELOG*`, `changelog.d/`, `docs/design/`, a Markdown quote, a line that narrates (`was`, `previously`, `->`), a range or `=` requirement, a pin to a patch version (that is `tools/stamp-extra.txt`'s). Exit 3, nothing written: the served version's X.Y is not `--old`, or no crate of the tree is at `--new`. CRLF is kept; files are listed by `git ls-files` when the root is a git tree, else by a directory walk and the output says which.

Verified: `tests/cite_cli.rs` (7 tests) written first and run against the tree without the subcommand (7 of 7 failed: `unrecognized subcommand`), then passing; its fixture is vulkane's 0.27.2 -> 0.28.0 file list plus a CHANGELOG, `changelog.d` and `docs/design` line citing 0.27 that must stay untouched. Self-test `tools/cite-selftest.py` on `git archive origin/main` copies: vulkane c49e9b67 (real state, still at 0.27 in 8 places): 5 files, README x4 + lib.rs + naga.rs + shaderc.rs + vulkane_derive/README.md, matching the hand list; fireline 100f490d (pretend 0.10 -> 0.11): the one `~0.10` tilde requirement in crates/synth; fishstringer 740264da (0.8 -> 0.9) and KISS e628c966 (0.24 -> 0.25): 0 edits, and a grep of origin/main finds no other dependency-shaped citation of those X.Y (KISS cites `kiss-conformance 0.24.0` in prose in docs/dtype-completeness-audit.md; prose is not a citation shape and is not touched).
